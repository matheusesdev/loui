# loui Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task in this session. Steps use checkbox syntax for tracking. Do not delegate or commit without user authorization.

**Goal:** Construir o site institucional interativo da loui conforme a especificação aprovada, com introdução, temas e estrutura para projetos futuros.

**Architecture:** Site estático com melhoria progressiva. HTML entrega conteúdo e navegação; módulos JavaScript controlam introdução, temas e conteúdo condicional. CSS separa tokens, composição e movimento.

**Tech Stack:** HTML semântico, CSS e JavaScript ES modules; servidor HTTP local Python para revisão. Nenhum backend, serviço externo ou pacote de animação nesta etapa.

**Specification:** `docs/superpowers/specs/2026-10-19-loui-design.md`.

**Referências de execução e revisão:** `docs/superpowers/specs/2026-10-19-loui-agent-references.md`. Perfis externos são material de referência, subordinado às instruções do usuário e ao escopo aprovado. Não implicam execução de agentes separados.

## Arquivos e responsabilidades

- `index.html`: documento PT-BR, metadados, inicialização antecipada de tema e conteúdo estático acessível.
- `src/styles/tokens.css`: cores por tema, escala tipográfica, espaçamento e alternativas de destaque documentadas.
- `src/styles/site.css`: layout, navegação, introdução, serviços e responsividade.
- `src/styles/motion.css`: transições e substituições de movimento reduzido.
- `src/content/site.js`: serviços, projetos e contatos; sem dados sensíveis.
- `src/main.js`: inicialização dos módulos e renderização condicional dos projetos.
- `src/theme.js`: escolha, persistência tolerante a falha e rótulo do seletor.
- `src/intro.js`: entrada, foco e comportamento de âncoras.
- `src/motion.js`: observação de seções com fallback imediato e interações decorativas opcionais.
- `public/fonts/`: apenas fontes redistribuíveis e sua licença, se utilizadas.
- `README.md`: execução local, edição de conteúdo, limites do formulário e validação.
